## Vì sao test luồng chính hỏng
```
tests/e2e/test_m1_flow.py:23: in eicar
    return base64.b64decode((FILES / "eicar.b64").read_text(encoding="ascii").strip())
E       OSError: [Errno 22] Invalid argument: '/src/core/tests/fixtures/files/eicar.b64'
```
Windows Defender nhận ra chuỗi thử EICAR dù đã lưu dạng base64 và chặn mở tệp trên ổ E:. Test dừng ngay bước đọc tệp mẫu,
chưa gửi request nào. Vì vậy luồng tải tệp → quét → cách ly/CAS → ledger → STH → neo → witness **chưa được chạy đầu-cuối**.

## Đã sửa (commit `28b114b`)
- Tệp mẫu đổi sang dạng XOR 0x5A rồi base64 (`core/tests/fixtures/files/eicar.xor5a.b64`); test, `fake_av.py` giải mã lúc chạy.
- Sau khi kéo `56bac6e` về máy trưởng nhóm, tệp mới nằm yên trên ổ E:, còn tệp cũ vẫn bị Defender chặn. Đây là dấu hiệu tốt,
  nhưng **chưa phải bằng chứng** test sẽ đạt.
